
# Contact Management System

## Project Overview
This is a Python-based Contact Management System. It helps users store and manage contact information.

## Features
- Add new contacts
- Display all contacts
- Search contacts by name
- Update contact details
- Delete contacts
- Validate phone numbers and email addresses
- Save contacts in JSON format
- Export contacts to CSV format

## Technologies Used
- Python
- Functions and Dictionaries
- JSON
- CSV
- Regular Expressions
- Unit Testing

## Project Files
- contacts_manager.py - Main program
- contacts_data.json - Stores contact data
- test_contacts.py - Unit tests
- README.md - Project documentation

## How to Run
Run this command:

python contacts_manager.py

## How to Run Tests
Run this command:

python -m unittest test_contacts.py
